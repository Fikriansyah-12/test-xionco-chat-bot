# 💬 Chatbot Next.js – AI Chat Interface

Chatbot ini dibangun menggunakan **Next.js App Router** dan **OpenAI/DeepSeek API**.  
Proyek ini menampilkan antarmuka modern (full screen + glassmorphism UI) untuk berinteraksi dengan model AI secara real-time.

---

## 🚀 Fitur Utama

- ✅ **UI modern** dengan efek kaca (glassmorphism) dan background aurora
- 💬 Chat **real-time** dengan streaming respons (via API route)
- 🔒 Mendukung **OpenAI API** atau **DeepSeek API**
- 🎨 Desain **full-screen responsif**, nyaman di mobile & desktop
- ⚡ Auto-scroll & auto-focus input
- 🕒 Timestamp & indikator mengetik
- 🌗 Siap dikembangkan ke mode dark/light & markdown rendering
